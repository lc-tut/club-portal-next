# ClubPortal画面デザインの要点

見た目の正は画面デザイン案(https://claude.ai/artifact/6zyXnBMFkbhcQioYxZddgG)とする。この文書は、デザイン案を開けないときのための要点のまとめ。食い違ったらデザイン案に合わせ、この文書を直す。

## 共通

- 見た目:白地に深緑1色のアクセント。装飾(グラデーション、影の多用、絵文字アイコン)は入れない。
- 色(デザイントークンとしてCSS変数で定義し、値を直書きしない):

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--ink` | `#1B1D1F` | 本文の文字 |
| `--muted` | `#565C63` | 補助の文字 |
| `--line` | `#D9DCE0` | 罫線、枠 |
| `--field` | `#8A9097` | 入力欄の枠 |
| `--ground` | `#F5F6F7` | ページの地 |
| `--surface` | `#FFFFFF` | カードの地 |
| `--accent` | `#0F6E5A` | 主ボタン、リンク |
| `--accent-weak` | `#E4F2ED` | 公開中の表示の地 |
| `--danger` | `#B42318` | 引き継ぎなど取り消せない操作 |

- 状態の色:公開中は緑系(`#0A4F40`/`#E4F2ED`)、必須項目が不足は橙系(`#6B3A00`/`#FFF4E5`)、非公開は赤系(`#8E1F17`/`#FDECEC`)。
- フォント:Noto Sans JP(セルフホストする)。
- 角丸:カード12px、入力欄とボタン8px。一覧のカードのアイコンと写真・動画は10px、詳細のアイコンは16px、詳細の外部リンクのボタンは錠剤型(999px)。
- 余白、文字の大きさ、部品の寸法も、デザイン案の値をトークン(`frontend/src/styles/tokens.css`)にして使う。
- 押せるものは`<button>`か`<a>`、タップ領域は44px以上、文字のコントラスト比は4.5:1以上。
- ページの最大幅:一覧とadminは1120px、詳細は880px、編集は760px、引き継ぎは640px。スマホ幅では1列に組み替わる。
- ヘッダー:左に「ClubPortal」。未ログインなら右に「編集者ログイン」、ログイン中なら「編集者としてログイン中」と「ログアウト」。adminは濃い色のヘッダーに「管理」の印を付ける。

## 1. 一覧(`/`)

- 見出し「サークル一覧」と、検索欄(ラベル「キーワードで探す」、ボタン「検索」)。
- 件数表示(「全N件」または「「語」の検索結果:N件」)。
- カードを3列前後のグリッドで並べる。カードはアイコン(72px)、サークル名、説明の冒頭2行。カード全体が詳細へのリンク。
- 該当なしのときは、メッセージと「検索をやめて全件を表示」ボタンを出す。

## 2. 詳細(`/clubs/{id}`)

- 上部にカバー(アイコンを横幅いっぱいに拡大してぼかしたもの)、その下にアイコン(128px)を重ねる。
- カバーに重ねるのはアイコンだけで、サークル名はカバーの下から始める(ぼかしたアイコンの上では名前が読めないため。デザイン案はカバーが無地の仮置き)。スマホ幅では名前をアイコンの下に回す。
- サークル名と、外部リンクのボタン(X、Instagram、YouTube、Webサイト。登録されたものだけ)。
- 「サークルについて」(説明。改行を保つ)、「活動スケジュール」(カレンダーの埋め込み)、「活動の様子」(写真のグリッドとYouTube動画)。値がない節は出さない。
- 最後に「サークル一覧へ戻る」。

## 3. 編集(`/edit`)

- 公開状態のバナー(公開中/まだ公開されていません/管理者により非公開)。
- 節ごとのカード:基本情報(サークル名、読み仮名、説明と文字数)、アイコン、活動スケジュール(カレンダーID)、活動の様子(写真6枚まで、YouTube動画3本まで)、リンク(固定の接頭辞付き入力欄)。
- 写真の上に「写っている人の同意を得た写真だけ」の注意を出す。
- 画像は選んだ時点で保存、文字の項目は「保存する」で保存することを明記する。
- 最後に「後任への引き継ぎ」への導線。

## 4. 引き継ぎ(`/edit/handover`)

- 引き継ぐと何が起きるか(後任だけが編集できる、自分はログアウトされる、メールは送られない)を先に示す。
- 後任のメールアドレスを2回入力し、「後任に伝えた」のチェックを入れたときだけ「引き継いでログアウトする」(危険色)を押せる。
- 入力したメールアドレスは照合用の値に変換して保存され、後から確認できないことを書く。

## 5. admin(`/admin`)

- 「サークル枠を作る」:代表者のメールアドレスを2回入力して作成。
- 「すべてのサークル」:サークル(アイコンと名前、未設定なら「(名前未設定)」)、状態、編集者の登録日、操作(「メールを変更」「非公開にする/公開に戻す」)。
- 「メールを変更」を押すと、その行の下に2回入力の欄が開く。変更すると今の編集者はすぐにログアウトされることを書く。
- 登録済みのメールアドレスは表示できないことを書く。
