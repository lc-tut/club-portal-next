# 個人情報と秘密情報の点検

要件定義の第5節(個人情報の扱い)と第9節(ログ)に照らして、次を点検する。`.env`類と`secrets/`の平文ファイルは開かない(存在するかどうかだけを確かめる)。

1. 追跡しているファイル(`git ls-files`)に、メールアドレス、学籍番号、氏名、電話番号、住所がないか。例示用の`example.com`などは除く。テストデータとフィクスチャも対象。
2. `secrets/`に`.sops.yaml`と`*.enc`以外のファイルが追跡されていないか。`.env`が追跡されていないか。
3. `db/migrations/`に、メールアドレスや氏名を平文で入れる列(`email`、`name_of_person`など)がないか。編集者の識別は`identifier_digest`だけになっているか。
4. ログ出力(`logging`、`logger`、`print`、`console.log`)に、メールアドレス、トークン、Cookie、セッションIDを渡している箇所がないか。
5. 追跡している画像に、EXIFの位置情報が残っていないか(Pillowで確かめる)。
6. 公開物(フロントの静的ファイル、ドキュメント)に、よく行く場所や個人が推測できる記述がないか。

報告のしかた:見つかったものだけを「ファイルと行」「何が問題か」「直し方」で並べる。何もなければ一言で済ませる。修正はしない。
